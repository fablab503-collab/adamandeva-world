Support

Help for adamandeva.world and the Adamandeva apps.

Send a message

Questions, bugs, corrections or takedown requests: send a message on GitHub. You need a free GitHub account, and messages there are public, so leave out anything private.

Corrections

If a story gets something wrong, tell us which story and what is wrong, with a link if you have one. We check it against the source.

Common questions

No stories show up. The app needs the internet the first time. After that it keeps a copy for offline reading. Pull down on the list, or use Settings → Refresh now.

An older story is missing. The app loads the newest stories first. Scroll to the end and tap “Load older stories”, or use Settings → Download the archive.

Text is too small or too big. Settings → Text size.

Where do stories come from? Most retell reporting by other newsrooms, named and linked on each story. They are written with Claude, an AI model by Anthropic, and a person reads each one before it goes live.
